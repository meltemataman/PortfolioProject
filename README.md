PortfolioProject

About the Project
A personal portfolio project developed using C# and ASP.NET Core.

Technologies Used
C#
ASP.NET Core
Entity Framework Core
SQL Server LocalDB
GitHub
Database

The project uses Entity Framework Core with the Code First approach.
Database tables are created and updated using migrations.

Main Feature
Experience management
Skills and skill items
Hero sections and titles
Contact information
Messages
Database Commands
Update-Database

Installation
Clone the repository.
Open the project in Visual Studio.
Check the database connection string in PortfolioContext.cs.
Run the project.
